Servers for the ssh-host environment

No keys are stored here: ssh uses your own ssh config and agent. A card runs in the server folder mapped to its project folder.

    Containers

    Used by the Container and Container on a server environments and by capsule checks. The image must already exist (it is never pulled) and contain python3; the container gets a read-only root, no capabilities, no network unless the launcher allows it, and these limits.
